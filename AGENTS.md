# Project Instructions for AI Agents

## Mandatory language policy

Use English for every technical artifact created or modified in this project, including source code, tests, file names, configuration, documentation, commit messages, and GitHub artifacts.

Use Spanish only for conversational explanations given directly to the user, unless the user explicitly requests another language.

## Scope

This repository is an original public portfolio project. Do not copy, mention, or depend on any third-party interview challenge, private container image, or proprietary OpenAPI contract.
